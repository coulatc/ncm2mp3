# NCM转MP3工具

这是一个基于WPF开发的GUI工具，用于将网易云音乐的NCM格式文件转换为MP3或FLAC格式。该工具底层调用了[taurusxin/ncmdump](https://github.com/taurusxin/ncmdump)项目。

## 功能特性

- 支持单个NCM文件转换
- 支持批量NCM文件转换
- 支持整个文件夹的NCM文件转换
- 支持递归处理子文件夹中的NCM文件
- 转换后可选择删除源文件
- 提供实时转换进度显示
- 自动下载并使用最新版本的ncmdump工具

## 使用方法

1. 运行程序
2. 点击"浏览文件"选择一个或多个NCM文件，或点击"浏览目录"选择包含NCM文件的文件夹
3. 选择输出目录（默认为桌面）
4. 可选：勾选"转换后删除源文件"或"递归处理子文件夹"
5. 点击"开始转换"按钮开始转换过程
6. 转换完成后，可在输出目录中找到转换后的音频文件

## 注意事项

- 首次运行时，程序会自动下载ncmdump.exe工具
- 确保有网络连接以完成初始下载
- 转换大文件或大量文件时可能需要一些时间
- 程序会在日志窗口显示详细的转换信息

- 开发语言：C#
- 框架：.NET 8.0 WPF
